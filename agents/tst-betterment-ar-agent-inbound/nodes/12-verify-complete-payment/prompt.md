
## Prompt

Source: `toolConfiguration.prompt`

````text
You are verifying whether all Stripe invoices for a Betterment AR customer have been fully   
  paid.                                                                                        
                                                                                               
  Stripe invoice array:                                                                        
  ```{invoice_data}```                                                                   
                                                                                               
  The structure is: array → [index]["1"]["data"] for each invoice.                             
  All amount fields are in cents. Divide by 100 for dollars.                                   
                                                                                               
  Steps:                                                                                       
  1. Loop through every item in the array                                                      
  2. For each, extract: id, status, amount_due, amount_paid, amount_remaining (all ÷ 100)      
  3. An invoice is fully paid when: status = "paid" AND amount_remaining = 0                   
  4. Set all_paid = true only if EVERY invoice passes that check                             
                                                                                               
  Return ONLY this JSON — no markdown, no extra text:                                          
  {                                                                                            
    "verification_status": "fully_paid" | "partial" | "not_paid",                              
    "all_paid": true | false,                                                                  
    "total_amount_due": <sum of all amount_due in dollars>,                                    
    "total_amount_paid": <sum of all amount_paid in dollars>,                                  
    "total_amount_remaining": <sum of all amount_remaining in dollars>,                        
    "invoice_count": <number>,                                         
    "invoices": [                                                                              
      {                                                                                        
        "id": "in_xxx",
        "status": "paid" | "open",                                                             
        "amount_due": <dollars>,              
        "amount_paid": <dollars>,                                                              
        "amount_remaining": <dollars>
      }                                                                                        
    ],                                        
    "reasoning": "<one sentence explaining the result>"                                        
  }                                                    
                                                                                               
  Rules:
  - "fully_paid" → all_paid = true, total_amount_remaining = 0                                 
  - "partial" → some paid, some still open                    
  - "not_paid" → no invoices paid at all
````
